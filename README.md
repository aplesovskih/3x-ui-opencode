# 3x-ui OpenCode

Скрипт установки панели [3x-ui](https://github.com/MHSanaei/3x-ui) на VPS с выбором прокси-сервера и выдачей сертификата по IP-адресу сервера.

## Возможности

- Установка панели 3x-ui официальным установщиком;
- **Интерактивный выбор прокси-сервера**:
  1. `nginx` — reverse proxy с TLS;
  2. `caddy` — reverse proxy с TLS;
  3. без прокси — панель с TLS напрямую;
- **Выдача сертификата по IP-адресу сервера**:
  1. Self-signed (`openssl`, SAN = IP, срок 365 дней);
  2. ZeroSSL (валидный сертификат по IP через `acme.sh`, срок 90 дней, автопродление);
- Автоматическое определение публичного IP и протокола панели;
- Настройка firewall (ufw / firewalld) и SELinux (для RHEL-семейства);
- Запуск с GitHub одной командой через `curl`.

## Требования

- VPS на ОС: Ubuntu, Debian, CentOS, Rocky Linux, AlmaLinux, Fedora;
- Запуск от `root` (или через `sudo`);
- Открытые/открываемые порты: `80/tcp` (для ZeroSSL), HTTPS-порт прокси (по умолчанию `8443`) или порт панели (по умолчанию `2053`).

## Установка

Запустите команду на сервере:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/aplesovskih/3x-ui-opencode/main/install.sh)
```

Скрипт пошагово:

1. проверит права и зависимости;
2. установит 3x-ui официальным установщиком (следуйте подсказкам установщика);
3. определит публичный IP сервера;
4. спросит порт веб-панели (по умолчанию `2053`);
5. предложит выбрать прокси-сервер: nginx / caddy / без прокси;
6. предложит выдать сертификат по IP: self-signed или ZeroSSL;
7. настроит TLS и reverse proxy, откроет порты в firewall;
8. выведет итоговую сводку с адресом панели.

## Управление

| Команда | Назначение |
|---------|------------|
| `x-ui` | интерактивное меню управления панелью |
| `systemctl status x-ui` | статус службы панели |
| `systemctl restart x-ui` | перезапуск панели |
| `systemctl status nginx` / `systemctl status caddy` | статус прокси |

## Замечания

- Учётные данные панели выдаёт установщик 3x-ui — сохраните их;
- ZeroSSL требует доступный извне порт `80` и валидный email для регистрации;
- Автопродление ZeroSSL-сертификата выполняет acme.sh (cron).
